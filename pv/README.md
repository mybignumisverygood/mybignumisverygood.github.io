# My PV Engine 是也！
此为何物? 顾名思义, 是我编写的一个开源 JS 文字 PV 编辑引擎  
虽然但是w 这是我的第一个正经 JS 项目, 所以大概会出现许许多多的奇怪的架构 / 行为, 希望我 1 年后再看我现在的代码不会看不懂ww  
# 渊源是何也？
这要追溯到约半年前的 2026 年 1 月份左右. 当时我萌生了 "使用原生 HTML+JS+CSS 还原我从 B 站上看到的那一堆炫酷的文字 PV" 的宏大想法! 遂花了几天完成了无色透明祭版本的《その銃口》PV.  
虽然最终效果还好 (也称不上 "太好"), 但是那一堆 await 和 async 的异步语法可谓是一言难尽w. 更别提最后也仅仅只是完成了最基础的 "纯白背景, 基本只有歌词在页面底部变动" 的效果…… 这令我有些许失望.  
而在半年后的 2026.8.9, 我重新拾起了我的文字 PV 项目! 但这次, 我希望自己使用原生语言从 0 到 1 编写一个独特的 PV 引擎w 算是一种情怀的传承物吧——  
在我编写这份 README.md 文档时, 我刚好马上就要加入"时间轴" 这一里程碑式的功能! 然后我才想起来这个项目甚至没有一个像样的 READMEww 所以就赶紧写了一份. 就是这样.
# 那么实用性呢?
哇嗯…… 这是一个有些一针见血的问题.  
实际上! 我自己也深深地意识到了, 这个项目在很大程度上是一个自娱自乐的产物w, 我对于 "让别人使用" 这件事不抱有太大期望 (当然, 你可以自由使用! 只要满足本项目的 MIT 开源协议即可).  
不过嘛…… 我觉得这个项目对于我的意义已经很大了! 毕竟是第一次 "实战演练" 嘛w. 当然! 如果能够帮到你或是让你感到有意思, 那便是再好不过了!
